# 2do-parcial-progamacion-basica

## Autor
**DANIEL EDUARDO DUPUY**

## Descripción

Este proyecto consiste en un programa de inventario desarrollado en C# para el rgistro de varios datos dentro de un restaurante y sus productos

## Funciones
- Registrar productos.
- Guardar el nombre y precio de cada producto.
- Mostrar la lista de productos.
- Modificar el precio de un producto.
- Calcular el precio total.
- Mostrar la lista actualizada.
- Validar posiciones incorrectas.

## Tecnologías utilizadas
- Lenguaje: C#
- Entorno de desarrollo: Visual Studio
